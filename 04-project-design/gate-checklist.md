# Gate 4: Project Design → Implementation

## Gate Purpose
Verify that the project plan is realistic, complete, and aligned with the architecture. Starting implementation without a sound plan leads to chaos.

## Checklist

### Activity Breakdown
- [ ] Every service has implementation + testing activities — *No gaps in the work breakdown?*
- [ ] Every service interaction has integration activities — *Integration isn't an afterthought?*
- [ ] Dependencies match the architecture's call graph — *Plan reflects reality?*
- [ ] Estimates use three-point estimation where uncertainty exists — *Honest about unknowns?*
- [ ] Activities are sized appropriately (1-5 days each) — *Trackable units of work?*

### Schedule
- [ ] Critical path is identified — *Do we know the minimum timeline?*
- [ ] No resource is overallocated — *People aren't assigned to 2 full-time tasks simultaneously?*
- [ ] Buffers are included and justified — *Plan accounts for reality?*
- [ ] Milestones provide meaningful checkpoints — *Can we verify progress?*
- [ ] Schedule accounts for overhead (meetings, reviews) — *Not 100% coding time?*

### Risk Management
- [ ] Risks from all categories are identified — *Technical, schedule, scope, resource, organizational?*
- [ ] All Critical and High risks have mitigation plans — *Not just a list of concerns?*
- [ ] Mitigations have specific, actionable steps — *Not "be careful"?*
- [ ] Triggers are defined for monitoring — *How do we know a risk is materializing?*
- [ ] Risk-architecture alignment is documented — *Which components are affected?*

### Team Readiness
- [ ] Skills are matched to activities — *Right people, right tasks?*
- [ ] Key person dependencies are identified as risks — *Bus factor addressed?*
- [ ] Team has reviewed and agreed to the plan — *Buy-in, not just assignment?*

### External Dependencies
- [ ] External dependencies are documented with timelines — *APIs, decisions, infrastructure?*
- [ ] Contingencies exist for external delays — *What if they're late?*

## Gate Decision
- **PASS**: All items checked. Proceed to Implementation.
- **FAIL**: Return to Project Design to address gaps.

## Gate Owner
The project lead and human stakeholder jointly make the gate decision.
