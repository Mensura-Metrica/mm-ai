## Output: Harness Configuration

Based on intake, the harness configures:

- [ ] Phase depth (standard / minimal / extended)
- [ ] Artefact detail level (brief / standard / comprehensive)
- [ ] Gate strictness (standard / strict)
- [ ] Evidence requirements

**Defaults:** Standard for greenfield, minimal for tight timeline, extended for high-risk.

---

## First Phase to Start

Based on this intake form, begin at:

- [ ] **Phase 0: Incubation** — New project, validating the idea
- [ ] **Phase 1: Discovery** — Problem known, validating solution
- [ ] **Phase 2+** — Already defined, go straight to requirements

**Recommendation:** Always start Phase 0 or 1, even for brownfield. It's your alignment checkpoint.
