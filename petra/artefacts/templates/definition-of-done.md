## DoD Checklist

### Code Quality

- [ ] Code follows adopted style guide
- [ ] No compiler warnings
- [ ] No static analysis warnings
- [ ] No security vulnerabilities (OWASP checked)

### Testing

- [ ] Unit tests written for new code (90%+ coverage)
- [ ] Unit tests passing
- [ ] Integration tests passing (if applicable)
- [ ] No existing tests broken

### Documentation

- [ ] Code comments explain non-obvious decisions
- [ ] Interface contracts updated (if changed)
- [ ] API documentation updated (if public API)

### Review & Handoff

- [ ] Code review completed
- [ ] All review comments addressed
- [ ] Reviewer approval received

### Deployment Readiness

- [ ] Deployment configuration updated (if needed)
- [ ] Database migrations tested
- [ ] Feature flag configured (if applicable)
