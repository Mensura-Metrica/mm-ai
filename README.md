# Petra

**Production methodology for software teams who ship quality.**

## The Problem

Everyone is vibe coding now. LLMs write code faster than ever. But speed without structure produces:

- Technical debt that compounds
- Architecture that rots
- Teams that can't sustain velocity
- Handoffs that lose context

The market is flooded with code that ships but doesn't scale.

## The Solution

Petra is a structured methodology harness — prompts, templates, and workflows that guide teams from concept through production. Works with any LLM and any ticketing system.

**While you're vibe coding, Petra ensures you're building enterprise-grade software.**

## Who It's For

- **Solo builders** — full-stack guidance without the process overhead
- **Teams** — consistent delivery regardless of who's coding
- **Enterprises** — governance without bureaucracy

## What's Included

| Section | Contents |
|---------|----------|
| **Phases** | 9 sequential phases (0–8) with gate checklists |
| **Personas** | 5 role guides: Sponsor, PM, Architect, Developer, QA |
| **Templates** | 20 artefacts: PRD, project plan, sprint tasks, test results, etc |
| **IDE Rules** | Single AI instructions file |
| **PM Tools** | Jira, Azure DevOps, Linear integrations |

## How It Works

1. Copy `petra/` to your project
2. Follow `SETUP.md` (2 minutes)
3. Start at `phases/0-incubation.md`
4. Complete gate criteria before each phase transition
